# 技术美术笔记

在 Obsidian 中打开本目录。实验笔记、概念笔记和附件按需创建并纳入 Git；.obsidian 和 .claudian 为本机状态，不提交。

学习入口：[[Guides/特效学习指南|特效学习指南]]。按特效类型查看资源、输入变量、计算流程和整体伪代码，包含 [[鼠标悬停透视形变]]、[[溶解出现与消失]] 和 [[卡牌拖拽与速度倾斜]]；可叠加特效在各篇末尾列出。

`Guides` 按算法顺序说明实现方式，`Experiments` 保留具体案例的实现、验证与限制，`Concepts` 解释通用机制。

实现案例：[[001_BalatroCardHover]]，核心概念：[[ClipSpaceW]]。概念笔记解释数学与渲染机制，实现笔记给出可复现步骤。

节点对照：[[001_BalatroCardHover_ShaderGraph]]，包括节点连接、坐标反算和 UV 插值修正。

双向溶解：[[002_BalatroCardDissolve]]，包含程序化像素遮罩、进入/退出参数、边缘着色和同步阴影。

卡牌拖拽：[[003_BalatroCardDrag]]，包含固定抓取偏移、位置与旋转阻尼、释放回位，以及后续悬停衔接的状态接口。算法指南：[[卡牌拖拽与速度倾斜]]。

后续计划：[[小丑牌卡牌特效待办]]，记录消融边缘粒子、随屏幕位置变化的阴影、默认顺时针透视动画，以及后续融合约束。

溶解边缘粒子改进版：[[004_BalatroDissolveParticles]]。悬停、拖拽与延迟溶解整合版：[[005_BalatroCardIntegrated]]。数据流和算法指南：[[溶解边缘粒子与交互整合]]。

3D 风格与动画计划：[[3D像素风格与程序动画实验路线]]，记录 006–011 的优先级、最小场景、参数和验收边界。首个最小实验：[[006_LowRes3DPixelated]]，比较分辨率、Point/Bilinear 与相机运动。

相机平移稳定化：[[007_PixelStable3D]]，比较连续相机、像素网格对齐与输出补偿，记录适用条件和边界残差。

低模风格变量：[[008_LoFiLowPoly]]，用树、岩石和地面分别比较几何细分、法线、底色色板、光照与输出分辨率。
