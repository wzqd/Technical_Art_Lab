# 004 · Balatro Dissolve Particles

研究问题：卡面遮罩与粒子如何共用同一份场数据，使粒子恰好从本次更新消失的边缘出生？

独立入口为 `Assets/_Lab/Experiments/004_BalatroDissolveParticles/Scenes/004_DissolveParticles_Minimal.unity`。菜单：`TechArtLab > 004 > Create or Open Minimal`。保留 [[002_BalatroCardDissolve]] 原有场景和代码；算法说明见 [[溶解边缘粒子与交互整合]]。

## 机制与资源职责

| 层面 | 实现 |
| --- | --- |
| Geometry | 卡面与阴影为 Quad；粒子是可旋转的小方片 |
| Pixel | 从 RFloat 数据纹理读取场值与阈值之差，再计算透明遮罩、双层边缘及染色 |
| Driver | CPU 计算 71×95 网格、检测可见转隐藏、按种子抽样发射、固定步长推进 |
| Pass | 阴影、卡面、粒子独立绘制，透明混合、不写深度；粒子排序在卡面前 |

`DissolveGrid` 保存场值、上一时刻可见性、已消耗单元和卡面 alpha；`EdgeParticleEmitter` 负责出生、随机参数与 ParticleSystem 模拟；`DissolveParticleController` 负责进入/退出、暂停、复位及全部材质参数写入；`DissolveParticleDemo` 负责输入和面板。

运行复用 003 的 Quad 网格及 002 的种子偏移静态函数，但不启用旧 Demo 组件。004 自己复制并导入了两张测试卡图，启用 Read/Write 用于读取 alpha，不修改 002 的纹理导入配置。

## 场数据与出生规则

**Unity Reproduction Choice**：将 002 的程序化场搬到 CPU 的固定逻辑网格，计算 $S=R-a$。卡面 Shader 用 $S>0$ 判断可见，粒子也使用同一数组的符号；完整端点保留 002 的 `d < 0.001` 分支。数据纹理使用线性数据、Point 过滤、Clamp、无 mipmap。

数组第 0 行表示卡片顶部。读取纹理时使用 `(uv.x, 1-uv.y)`；出生位置反向转换回底部为原点的局部 UV。网格坐标两轴都除以 95，与 002 的公式一致。冻结场时间时缓存三组波纹，进度改变只重新求阈值、余弦重映射和边缘惩罚。

退出播放时，只有“上一步可见、这一步隐藏、卡图 alpha > 0.01、尚未消耗”的单元进入候选集合。候选单元立即标记已消耗，然后以 4% 的概率发射；未抽中的单元也不会重复尝试。进入、手动调进度和复位不发射，避免整张卡突然产生一批粒子。

粒子出生在候选单元中心，经当前卡牌 Transform 转到世界坐标。速度方向取场值负梯度，修正顶部原点的 Y 方向后叠加随机扰动；梯度很小时使用随机平面方向。粒子出生后使用世界空间模拟，不跟随卡牌后续平移和旋转。

## 参数与操作

| 操作或参数 | 默认行为 |
| --- | --- |
| `1` / Orange exit | 黑桃 A 从完整到隐藏，边缘发射粒子 |
| `2` / Green entry | 锁卡从隐藏到完整，不发射粒子 |
| `R` / Reset visible | 黑桃 A 恢复完整，清除粒子 |
| Space | 冻结或恢复进度、场时间与粒子 |
| 进度滑条 | 停止播放并清除粒子，重建可见性历史 |
| Fixed seed 1234 | 固定图案和粒子抽样，便于重放对照 |
| New seed on replay | 每次播放开始换种子，播放中不重新随机 |
| Show birth points | Game 视图显示本次子步出生点，Scene Gizmos 也可显示 |
| Color / Mask / Field | 查看颜色、遮罩或重建的原始场值 |
| 粒子大小 | 1–3 个逻辑像素 |
| 粒子寿命 | 0.4–0.8 秒，后半段淡出并持续缩小 |
| 粒子速度 | 每秒 0.1–0.3 个卡高 |
| 最大存活数量 | 512，Inspector 可调；达到上限不再发射 |

播放控制器没有自己的 Update，调用方负责 `Tick(dt)`；它累积到 1/60 秒后执行 `StepFixed`。005 直接调用 `StepFixed`，不能再同时调用 Tick。单帧最多接受 0.1 秒，卡顿不补算全部缺失时间。固定种子重现要求相同参数、步长与输入。

公开接口为 `BeginExit(seed)`、`BeginEntry(seed)`、`SetProgress(value)`、`Tick(dt)`、`ResetVisible()`。`completed` 在进度到达端点时触发一次，不等待存活粒子结束。`IsComplete` 特指已完成退出并隐藏；进入完成可通过 Playing 和 Progress 判断。
