# 002 · Balatro Card Dissolve

研究问题：同一个程序化像素遮罩，如何通过进度方向和边缘参数，分别表现卡牌消失与出现？

独立场景：`Assets/_Lab/Experiments/002_BalatroCardDissolve/Scenes/002_CardDissolve_Minimal.unity`。使用固定卡片、自制黑桃 A 与锁卡测试图，分别观察溶解场、可见遮罩和最终着色。

## 实验范围

| 层面 | 当前实现 |
| --- | --- |
| Geometry | 正交相机，卡面和偏移阴影各为四顶点、两个三角形的 Quad |
| Pixel | 局部像素量化、三组程序化波纹场、阈值遮罩、可选两层边缘、剩余卡面染色 |
| Driver | 进入与退出分别播放；进度与场时间独立控制；暂停、手动调节、固定状态 |
| Pass | 同一个 Unlit Shader 分别绘制阴影与卡面；透明混合，关闭深度写入，以排序顺序保证阴影在后 |

[[001_BalatroCardHover]] 的悬停形变、拖拽、粒子和原作 CRT 后处理不属于本场景。保留此 Minimal 场景，后续在另一个场景组合效果。

## 原作证据

**Observation**：参考录像中黑桃 A 先出现孔洞，随后留下橙色条带并消失；锁卡从绿色不规则区域扩张为完整卡片。

**Verified（抓帧源码与参数）**：`dissolve+particle.rdc` 和 `chain.rdc` 导出的溶解顶点与片元代码分别完全一致。退出抓帧的 `dissolve≈0.499722`，使用深灰和橙色；进入抓帧的 `dissolve≈0.333273`，只启用绿色第一层，第二层 alpha 为 0。

原始证据仅本地保留在 `References/002_BalatroDragDissolveParticles/analysis/`：

- 退出：`capture.xml` 的 chunkIndex 584（阴影）、603 与 623（卡面层）。
- 进入：`chain/capture.xml` 的 chunkIndex 573（阴影）、603（卡面）。
- 两份 `shader_chunk_87_0.glsl` 为实际导出的片元代码，`draw_states.json` 记录帧内 uniform 提交。

这些编号是 XML 的 chunkIndex，不是 RenderDoc UI 的事件编号。验证范围为捕获命令、参数与 Shader 源码，没有做原作 GPU 重放隔离。

**Inference**：结合连续录像，进入适合由进度 1→0 驱动。单帧 RDC 不能确认 CPU 动画时长、插值曲线或时间更新速度。

**Unity Reproduction Choice**：默认播放时长 1.2 秒、线性进度驱动，场时间默认冻结便于观察；测试纹理、相机、阴影位移、颜色空间处理都是本实验选择。没有声称与原作最终画面逐像素匹配。

## 局部坐标与像素量化

`CardDissolve.shader` 使用单张卡面纹理，无需原作图集坐标换算。Mesh UV 原点在左下，送入溶解场前转换成左上原点：

```hlsl
float2 localUV = float2(uv.x, 1.0 - uv.y);
float2 gridUV = floor(localUV * size) / max(size.x, size.y);
```

`size` 是逻辑像素尺寸，默认 `(71,95)`；纹理本身为 `142×190`，每个逻辑像素对应两个纹素。两个方向都除以尺寸最大值，保留等尺寸的像素网格。因此量化后的 X 范围约为 0–71/95，不能改成两轴各自除以宽高，否则波纹与边缘惩罚都会改变。

纹理使用 Point 过滤、禁用 mipmap 与压缩，`Non Power of 2=None`，避免导入器把 142×190 自动缩放后产生新的半透明边界。

## 溶解场与可见性

对量化坐标平移、缩放，构造三个随时间偏移的场分量。各分量组合距离上的正弦或余弦与横纵坐标上的正弦或余弦，再经过余弦重映射。完整公式保留在 `DissolveField` 函数中，没有额外的噪声纹理。

溶解进度 $d\in[0,1]$ 对应阈值：

$$
a(d)=1.02d^2(3-2d)-0.01
$$

令程序化场及边缘惩罚后的值为 $R(u,v,t,d)$，可见性为：

$$
V=\begin{cases}
1,&d<0.001\\
1,&R>a(d)\\
0,&\text{其他}
\end{cases}
$$

输出 alpha 为卡面 alpha 乘 $V$。原作使用 alpha=0，本实验同样不使用 `discard`。阈值实际范围是 -0.01 到 1.01，不能照搬原源码注释中不准确的 -0.1 到 1.1。

`R` 本身也依赖进度和时间，因此“固定噪声图＋一个阈值”只是概念近似。Field 视图显示 `saturate(R)`，Mask 视图显示最终可见部分。冻结时间后调整进度，可以把动画中的两种变化分开观察。

## 随机图案与可复现种子

图案不是噪声纹理。初版每次重播恢复相同场时间且默认冻结，因此相同进度显示相同孔洞。现在默认启用 `New pattern each replay`，每次按进入/退出按钮重新选取种子。暂停与继续不会换种子，避免图案在动画中突然跳变。

`patternSeed` 通过整数混合生成二维偏移，传入 Shader 的 `_PatternOffset`，加在三组波纹的输入坐标上：

```hlsl
float2 p = (gridUV - 0.5) * 2.3 * largest + _PatternOffset.xy;
```

随机化相当于在程序化场中选取不同的区域。卡面 UV、像素网格与边缘惩罚的坐标保持不变；阴影使用相同偏移。偏移一旦选定就保持稳定，不逐帧重新随机。随机数生成器独立于 Unity 全局随机状态。

种子 0 对应零偏移，保留原来的图案。相同种子、预设、时间、进度和其他参数在当前图形后端产生相同结果；只固定种子而继续推进场时间，图案仍会变化。种子偏移是本实验扩展，不是已确认的原作随机算法。

## 边缘与染色

令 $b=\max(0,0.5-|a-0.5|)$，当 $R$ 刚好高于阈值时进入着色带：

- 内层：$a<R<a+0.5b$，使用第一层颜色。
- 外层：$a+0.5b\le R<a+0.8b$，第二层启用时使用第二层颜色。
- 其他可见部分：保留经过整体染色的卡面。

`Edge width` 同时乘两层宽度。进度接近中间时带宽较大，接近端点时缩小。第二层 alpha=0 时不绘制外层颜色，保留该处的卡面颜色。

剩余卡面使用 `Tint strength × d` 向有效边缘色混合：优先第二层，否则第一层。默认强度为抓帧代码中的 0.6。

| 预设 | 第一层 RGB | 第二层 RGBA | 默认场时间 | 播放方向 |
| --- | --- | --- | --- | --- |
| Orange exit | (55,66,68)/255 | (253,162,0,255)/255 | 766.55188 | 0→1 |
| Green entry | (75,194,146)/255 | (0,0,0,0) | 286.88257 | 1→0 |

Unity Linear 项目把预设作为显示 RGB，先转为 linear 再通过 `SetVector` 写入参数，避免 `SetColor` 再次转换。它保证本实验中纯边缘色按预设显示；原作完整色彩管线和 CRT 尚未匹配。

## 阴影与动画驱动

阴影与卡面共享材质，通过各自的 `MaterialPropertyBlock` 使用相同进度、场时间、逻辑像素尺寸和卡面纹理。阴影分支输出黑色，alpha 为卡面 alpha×可见性×0.3，不参与边缘染色。

阴影只是向右下偏移的第二张 Quad，不是灯光投射的实时阴影。孔洞在卡片局部坐标中计算，因此阴影移动不会改变遮罩形状。

`CardDissolveDemo.Tick(dt)` 分别更新两个量：

- 未冻结时，场时间增加 `dt`。
- 正在播放时，进度增加或减少 `dt/duration`，到达端点后停止。

暂停播放只暂停进度；取消 Freeze 后场图案仍会变化。要完全静止，暂停播放并冻结场时间。进入/退出按钮会重新加载各自预设并从对应端点播放，滑条会暂停播放并直接设置进度。

## 场景操作

通过 `TechArtLab > 002 > Create or Open Minimal` 打开场景，进入 Play。

| 操作 | 作用 |
| --- | --- |
| `1` / Orange exit | 加载橙色预设，从完整卡片开始消失 |
| `2` / Green entry | 加载绿色预设，从隐藏状态开始出现 |
| Space / Play、Pause | 播放或暂停进度 |
| `F` / Freeze field time | 冻结或继续场图案变化 |
| New pattern each replay | 默认开启；进入/退出重新播放及到达终点后的重播会更换种子 |
| Seed | 输入 0–65535；关闭自动随机可重复使用该种子 |
| `N` / New | 立即换一个图案，保持当前进度与场时间 |
| Original | 种子恢复为 0，并关闭自动随机；场时间可由预设按钮恢复 |
| `R` / Visible | 进度设为 0 |
| Hidden | 进度设为 1 |
| 进度滑条、0/0.25/0.5/0.75/1 | 固定状态检查 |
| Color / Mask / Field | 最终颜色、可见遮罩、阈值前的场值 |
| Edge width / Card tint | 调整边缘宽度与剩余卡面染色 |

Inspector 还可调整逻辑像素尺寸、两层颜色和阴影透明度。两层颜色中的 alpha 决定该层是否启用；预设按钮会恢复预设颜色和场时间。
