# 溶解出现与消失

## 效果与原理

为图像中的每个位置提供一个灰度值，将它与随进度变化的阈值比较：高于阈值的像素保留，其余像素透明。再给刚刚高于阈值的一小段区域着色，形成溶解边缘。

消失时提高进度，出现时降低进度。网格保持完整，孔洞由像素透明度形成。

下面先给出可独立转写的通用算法：静态灰度场、单层边缘色。它是实现骨架；现有 002 的程序化场与双层着色作为后面的替换模块说明。

## 所需资源

| 资源               | 职责                             |
| ---------------- | ------------------------------ |
| Quad 与局部 UV      | 承载图像，UV 范围 0–1                 |
| 卡面 RGBA 纹理       | 提供基础颜色和透明轮廓                    |
| 灰度噪声纹理           | 提供 0–1 的场值；作为数据读取，不做 sRGB 颜色转换 |
| Unlit 材质与 Shader | 计算遮罩、边缘色和最终透明度                 |
| 进度驱动脚本           | 更新进度、播放方向与停止状态                 |

使用程序化函数生成灰度场时，可以省去噪声纹理。像素化坐标、阴影和粒子均不是基础算法的必需资源。

## 输入与中间变量

| 变量 | 类型、空间或单位 | 用途 |
| --- | --- | --- |
| uv | float2，卡片局部坐标 | 同时定位卡面与溶解图案 |
| d | float，0–1 | 进度：0 完整，1 隐藏 |
| direction | +1 或 -1 | +1 消失，-1 出现 |
| duration | float，秒，大于 0 | 从一个端点播放到另一个端点的时长 |
| dt | float，秒 | 当前帧时间间隔 |
| e | float，正数 | 边缘带宽，单位为场值差，不是屏幕像素 |
| edgeColor | float3，与卡面一致的工作颜色空间 | 边缘 RGB |
| card | float4 | 采样得到的原始卡面 RGBA |
| N | float，0–1 | 当前像素的灰度场值 |
| a | float | 由进度生成的阈值 |
| V | 0 或 1 | 可见遮罩 |
| E | 0 或 1 | 边缘遮罩 |

## 算法流程

### 1. 每帧更新溶解进度

开始消失时设置 d=0、direction=+1；开始出现时设置 d=1、direction=-1。播放期间更新：

$$
d\leftarrow\operatorname{clamp}(d+direction\cdot dt/duration,0,1)
$$

到达播放方向对应的端点后停止更新，向 Shader 上传 d。

**输出**：本帧进度。反向播放只改变 direction，后面的像素计算保持不变。

### 2. 为当前像素读取颜色与场值

用局部 uv 采样卡面，得到 card；用相同的局部坐标采样灰度场，得到 N。

**输出**：card 和 N。图案附着在卡片上，对象移动不会改变同一个局部位置的场值。

### 3. 将进度转换为阈值

$$
a=1.02d^2(3-2d)-0.01
$$

$d^2(3-2d)$ 让阈值在两端变化较慢。将范围扩展为 -0.01 到 1.01，使 d=0 时阈值低于所有 N，d=1 时阈值高于所有 N。

**输出**：阈值 a。d 表示动画进度，不保证等于已经消失的面积比例。

### 4. 计算可见遮罩

$$
V=\begin{cases}1,&N>a\\0,&N\le a\end{cases}
$$

**输出**：V。固定灰度场中，低值区域先消失，高值区域后消失。

### 5. 从可见区域中取出边缘带

当 $0<d<1$ 且 $a<N<a+e$ 时令 E=1，其余为 0。

这段区域仍然可见，但它的场值接近隐藏阈值，因此位于孔洞边界附近。端点关闭边缘色，保证完整状态显示原卡面。

**输出**：E。e 控制场值区间宽度；场变化缓慢的位置，色带在画面中可能更宽。

### 6. 合成颜色与透明度

$$
RGB_{out}=\operatorname{lerp}(card.rgb,edgeColor,E)
$$

$$
\alpha_{out}=card.a\cdot V
$$

边缘色只修改 RGB，基础算法始终保留卡面原来的透明轮廓。使用 Alpha 混合，将输出颜色合成到背景上。

**输出**：带边缘色的溶解图像。

## 整体伪代码

```text
开始消失：
    d = 0
    direction = +1
    playing = true

开始出现：
    d = 1
    direction = -1
    playing = true

每帧（Driver）：
    如果 playing：
        d = clamp(d + direction * dt / duration, 0, 1)
        如果 direction == +1 且 d == 1，或 direction == -1 且 d == 0：
            playing = false
    上传 d

每个顶点（Geometry）：
    正常变换顶点位置，传递局部 uv

每个片元（Pixel）：
    card = 采样卡面(uv)
    N = 采样灰度数据(uv)
    a = 1.02 * d*d*(3-2*d) - 0.01
    V = N > a ? 1 : 0
    E = (0 < d < 1 且 a < N < a+e) ? 1 : 0
    rgb = lerp(card.rgb, edgeColor, E)
    alpha = card.a * V
    输出 (rgb, alpha)

绘制（Pass）：
    一个透明 Unlit Pass
    Blend SrcAlpha OneMinusSrcAlpha
    ZWrite Off，Cull Off
```

## 002 的替换模块：程序化场与双层边缘

保留“进度 → 阈值 → 可见遮罩 → 着色”的结构，替换场的来源和颜色规则。以下对应现有案例，使用前述 d、a、uv 与 card，并增加这些输入：

| 输入 | 含义 |
| --- | --- |
| size / `_PixelSize` | 逻辑像素宽高，各分量至少为 1，当前 71×95 |
| fieldTime / `_FieldTime` | 独立场时间；未冻结时每帧增加 dt |
| c1、c2 / `_BurnColor1`、`_BurnColor2` | 两层 RGBA；alpha 大于 0.01 表示启用 |
| width / `_EdgeWidth` | 边缘宽度倍数，当前 0–2 |
| tint / `_TintStrength` | 剩余卡面染色强度，0–1 |

### 1. 量化局部坐标

```text
localUV = (uv.x, 1-uv.y)
L = max(size.x, size.y)
q = floor(localUV * size) / L
p = (q - 0.5) * 2.3 * L
```

q 使用左上原点，并让同一逻辑像素内的输入相同。两轴统一除以 L，保留网格比例；p 为后续波纹计算坐标。

### 2. 合成三个随时间移动的波纹

```text
t = fieldTime * 10 + 2003
p1 = p + 50 * (sin(-t/143.6340), cos(-t/99.4324))
p2 = p + 50 * (cos( t/53.1532),  cos(-t/61.4532))
p3 = p + 50 * (sin(-t/87.53218), sin(-t/49.0000))

f = (1 + cos(length(p1)/19.483)
       + sin(length(p2)/33.155) * cos(p2.y/15.73)
       + cos(length(p3)/27.193) * sin(p3.x/21.92)) * 0.5
R = 0.5 + 0.5 * cos(a/82.612 + (f-0.5)*3.14)
```

三个移动坐标生成不同方向与频率的波纹，合成后形成不规则场。数值系数控制本案例的图案风格，三角函数参数按弧度计算。

### 3. 加入边缘惩罚并生成遮罩

```text
border = max(q-0.8, 0) + max(0.2-q, 0)
R = R - (border.x + border.y) * (5+5*d) * d
V = d < 0.001 ? 1 : (R > a ? 1 : 0)
```

边缘惩罚会降低靠近指定边界区域的场值，并随 d 增强。因此 R 同时依赖坐标、时间和进度，不是固定噪声贴图。

### 4. 先整体染色，再覆盖两层边缘

```text
如果 d > 0.01：
    如果 c2.a > 0.01：card.rgb = lerp(card.rgb, c2.rgb, tint*d)
    否则如果 c1.a > 0.01：card.rgb = lerp(card.rgb, c1.rgb, tint*d)

b = max(0, 0.5-abs(a-0.5)) * width
如果 d >= 0.001 且 card.a > 0.01 且 c1.a > 0.01
   且 a < R < a+0.8*b：
    如果 R < a+0.5*b：card = c1
    否则如果 c2.a > 0.01：card = c2

card.a *= V
输出 card
```

b 在中段较大、两端趋近于零。第一层覆盖更贴近隐藏区的部分，第二层覆盖外侧。此案例替换整个 RGBA；与前面的基础算法只覆盖 RGB 有区别。c2 关闭时外层保留染色后的卡面，c1 关闭时不执行两层边缘覆盖。

## 实现约束

- 灰度值与颜色应区分：噪声是数据，边缘颜色需要与项目工作颜色空间一致。
- 暂停进度和冻结场时间是两个独立状态；时间继续变化时，反向播放不等于严格倒放。
- 基础算法的 e 是场值宽度；002 的 width 是倍数，两者不能直接按相同数值替换。
- 当前采用透明混合与 alpha=0 隐藏像素；若改为不透明材质加裁剪，需要同时重新设计 Pass 状态。

## 可叠加特效

- 同步溶解的偏移阴影（002 已实现）
- 沿溶解边界发射碎屑粒子
- 边缘发光与 Bloom
- 烟雾与热扰动
- 从点击位置向外扩散的溶解
- 拖拽运动与悬停透视形变
- 出现瞬间的缩放回弹
