# 溶解边缘粒子与交互整合

## 效果与原理

沿 [[溶解出现与消失]] 的遮罩边界生成小方片，再把它与 [[卡牌拖拽与速度倾斜]] 组合。卡牌仍通过像素透明度消失，粒子是独立绘制和运动的对象；二者通过共同的场数据联系。

本篇对应 004、005 当前实现。CPU 计算小尺寸场纹理，让 Shader 和发射器读取同一份结果；适合当前单张像素卡牌实验，不作为大型 GPU 粒子系统的通用性能方案。

## 所需资源

| 资源 | 职责 |
| --- | --- |
| 可读取 alpha 的卡图 | 排除透明处的粒子出生 |
| 71×95 浮点数组与 RFloat 纹理 | 保存场值减阈值，数组与纹理共享相同网格 |
| 单元历史数组 | 上次是否可见、本次是否跨越、是否已消耗 |
| Quad 与卡面 Shader | 用数据纹理生成遮罩、边缘和染色 |
| 世界空间 ParticleSystem | 模拟方片速度、角度、寿命、缩小与淡出 |
| 单一播放/交互驱动 | 保证输入、倒计时、场数据和粒子只更新一次 |

## 输入与中间变量

| 变量 | 含义与单位 |
| --- | --- |
| d、a | 溶解进度与由进度生成的阈值 |
| R[i]、S[i] | 单元场值、场值与阈值之差 S=R-a |
| visible[i] | 单元上一次更新的可见状态 |
| consumed[i] | 本轮退出是否已经处理过该单元的消失 |
| alpha[i] | 对应卡图单元中心的透明度 |
| q | 候选单元发射概率，默认 0.04 |
| H | 卡牌世界高度 |
| o、p、home | 固定抓取偏移、显示中心和原位，世界空间 |
| elapsed、delay | 离位倒计时的已计时间、延迟，秒 |

## 算法流程

### 1. 在逻辑网格上计算场

使用 002 的波纹函数，固定种子只在开始播放时选取。CPU 网格第 0 行对应顶部；网格坐标两轴除以最大逻辑尺寸 95，保留原场的比例。

每步计算 $S_i=R_i(d,t,seed)-a(d)$，整张数组上传为 Point 采样、Clamp、无 mipmap 的线性数据纹理。冻结场时间时缓存与进度无关的三组波纹，减少重复计算。

Shader 使用 $S_i>0$ 判断可见；边缘带从 $0<S_i<b$ 一类区间取得。Field 调试视图才加回阈值重建 R。直接对 S 比较可以避免先加回阈值再减去造成的额外舍入差异。

### 2. 从跨越阈值的单元选择出生点

令当前可见性为 V，新候选条件为：

$$
C_i=visible_i\land\neg V_i\land\neg consumed_i\land(alpha_i>0.01)
$$

端点 d 接近 0 时按原算法强制完整。每个候选立即标记 consumed，然后以概率 q 抽样；最后更新 visible。标记发生在随机抽样之前，所以未抽中者也不重复尝试。

这不是沿整张卡的外轮廓发射，也不是对当前色带每帧持续发射。候选表示本次时间步跨过消融阈值的区域；快进时可能覆盖较宽区域，因此用固定小步长控制发射时间精度。

### 3. 把局部出生点转换到世界

对于网格单元 `(x,y)`，局部 UV 为：

$$
uv=\left(\frac{x+0.5}{71},1-\frac{y+0.5}{95}\right)
$$

局部位置为 `(uv.x-0.5, uv.y-0.5, -0.015)`，通过当前卡片 Transform 转成世界位置。Z 的小偏移让粒子位于卡片前侧；排序也在卡面之后绘制。

近似取 S 的负梯度，让粒子朝已消融侧散开。数组 Y 向下、世界 Y 向上，需要反转梯度的 Y 解释。方向加入少量随机扰动，零梯度处回退到随机平面方向。

初速度大小为随机系数乘 H；方片大小为逻辑像素数乘 H/95。这样缩放卡片时碎屑尺寸和速度保持相对比例。方向只使用旋转变换，避免再把缩放重复乘入速度。

### 4. 发射后独立模拟

将世界出生位置和初速度交给 ParticleSystem，使用 World 模拟空间。之后移动卡片不会把已发射的碎屑一起拉走。

发射、模拟均由固定时钟控制，关闭系统自动 Emission 与 Shape。使用独立随机序列，不消耗全局 Unity 随机状态。粒子达到容量上限时跳过新发射，不创建额外对象。

进入播放不启用发射。手动调进度、复位和重播会清除粒子，并以新的进度重建历史；暂停不推进场、进度或粒子。

### 5. 在整合版中管理一次拖拽

按下时记录固定抓取偏移，当帧将 hover 写为 0。以 003 的实际中心 p 判断离位：

$$
\lVert p-home\rVert>0.03H
$$

第一次越过后锁定 Countdown，不再根据当前位置撤销。拖回原位也继续增加 elapsed；只有收到释放事件且溶解尚未开始，才清零并回位。

达到 delay 后开始退出，切换到 Dissolving。此后释放只结束捕获，让中心停在释放处；角度回正但溶解继续。Hidden 禁止新的命中，存活碎屑继续衰减。

### 6. 用一个更新顺序消除冲突

先采集按下和松手，再执行固定子步：拖拽运动 → 离位/计时 → 溶解场 → 粒子 → 悬停状态。松手优先于计时，可以确定截止时刻的行为。

渲染属性统一由溶解组件写入，005 不同时挂载旧 Demo。位置只由拖拽控制器写入。只有回位稳定、卡面完整且鼠标仍在卡面内时恢复 001 悬停。

## 整体伪代码

```text
开始退出(seed)：
    选择退出卡图与颜色；进度 = 0
    清除粒子，重置独立随机序列和单元 consumed
    计算场并记录初始 visible

每个效果子步（1/60 秒）：
    若暂停：不推进
    更新进度与可选的场时间
    计算所有 S = R - threshold，上传数据纹理
    对每个逻辑单元：
        V = 完整端点 或 S > 0
        crossing = 旧 visible 且非 V 且未 consumed 且 alpha > 0.01
        若 crossing：标记 consumed
        若退出正在播放 且 crossing 且随机抽中 且未达容量：
            在当前卡片的单元中心发射世界空间方片
        visible = V
    由同一时钟模拟已存在粒子

整合版每帧输入：
    若有效按下：捕获输入，hover = 0，清零本次计时
    若释放且尚未溶解：取消计时，返回原位
    若释放且正在溶解：停止抓取，保持释放中心

整合版每个子步：
    更新拖拽位置与倾角
    若正在拖动且第一次越过距离阈值：进入 Countdown
    若 Countdown：elapsed += dt
    若 elapsed 达到 delay：开始退出，进入 Dissolving
    更新溶解与粒子
    若退出完成：进入 Hidden，释放捕获
    若正常返回并稳定：允许恢复 hover

卡面像素：
    从场纹理读取 S
    以 S 生成透明遮罩、边缘与染色
```

伪代码表达数据关系；当前代码先模拟上一时刻存活粒子，再发射本步新粒子，避免新粒子刚出生就被提前推进一个完整子步。

## 实现约束

- CPU 与 GPU 必须共用同一网格、种子、时间、阈值及原点定义；alpha 也要来自同一卡图。
- 当前 71×95 网格、RFloat 数据纹理和单卡场景已验证；网格尺寸是当前实现常量，不是可任意变化的面板参数。
- 固定种子不保证不同算法版本或不同参数的结果一致；调试时固定时间和输入轨迹。
- 粒子出生按刚消失单元中心近似，不是沿像素边缘求连续几何曲线。
- 005 溶解期间关闭 hover，因此 Transform 换算与显示几何一致；若将来允许 Shader 形变和发射同时存在，需要为出生位置应用同一形变。
- 单次 dt 最多接受 0.1 秒；长时间卡顿会延长实际墙钟完成时间。
- 共享 HLSL 函数时，顶点和片元入口声明保留在 Shader 的 HLSLPROGRAM 中，不能依赖普通 include 自动导入 pragma。

## 可叠加特效

- 进入时粒子聚合或向外发射
- 粒子阴影与随屏幕位置变化的卡片阴影
- 默认顺时针透视动画
- 消失后的卡牌重生、队列或容器规则
